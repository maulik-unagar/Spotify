# 🎵 Spotify

A visually stunning and responsive Spotify web player UI clone that brings your favorite playlists to life. Built with modern design elements, smooth interactivity, and clean code architecture.

---

## ✨ Features

- 🎧 Clean and modern Spotify-inspired layout
- 📁 Dynamic song list fetched from a local server
- 🎵 Interactive playlist with play/pause/next buttons
- 📱 Fully responsive for mobile and desktop
- 🎨 Dark theme with animated cards and hover effects
- 🍔 Mobile hamburger menu and sidebar toggle
- ⚡ Smooth UI animations and event handling
